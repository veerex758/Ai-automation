# Aivanta visual design direction

This document is the source of truth for the product's visual direction. Keep new pages and features consistent with the approved Aivanta concept: premium, modern business software with a dark emerald workspace, crisp white surfaces, and bright lime-green action accents.

## Visual identity

- **Brand:** Aivanta — confident, calm, capable, and approachable.
- **Core palette:** deep forest/emerald green, near-black green, white, soft off-white, and restrained lime accents.
- **Supporting colors:** muted violet, blue, and warm orange only for distinct workflow types, statuses, or data categories.
- **Typography:** clean modern sans-serif; strong, compact headings and highly legible interface text.
- **Shape language:** rounded cards and controls, subtle borders, restrained shadows, generous spacing, clear hierarchy.
- **Iconography:** simple, consistent line or geometric icons. Avoid mixing unrelated icon styles.

## Product UI direction

- Marketing site: bold, high-contrast dark green hero, bright lime primary CTA, clear product preview, then clean light sections explaining value and capabilities.
- App workspace: dark green navigation/sidebar paired with a bright, readable content canvas; clear active states and uncluttered top bar.
- Dashboard: meaningful metric cards, readable charts, clear workflow status badges, recent activity, and quick actions.
- Visual workflow builder: spacious dotted/grid canvas, distinct trigger/action/condition nodes, clear connectors, and obvious save/test/activate controls.
- AI assistant: integrated assistant panel using the same design system, with readable conversation, explicit proposed steps, and review/approval before consequential actions.
- Mobile: adapt layouts and actions for narrow screens rather than merely shrinking the desktop UI.

## Interaction principles

- Make the primary action obvious on every screen.
- Use lime for primary calls to action and positive highlights, not as a decoration everywhere.
- Use consistent hover, focus, disabled, loading, empty, success, and error states.
- Ensure keyboard navigation, visible focus rings, accessible contrast, and reduced-motion support.
- Keep copy concise and professional. Avoid fake urgency, excessive gradients, and visual clutter.
- Clearly label demo/sample data and unavailable integrations. Never make a mock feature look live.

## Implementation rules

1. Reuse the existing CSS tokens and shared components where possible; do not invent a separate style for each page.
2. Build responsive layouts for desktop, tablet, and mobile.
3. Preserve the approved palette, spacing, typography, border, and status patterns across all new features.
4. The concept image is a visual north star, not a claim that every pictured feature is implemented. Build the actual product incrementally and honestly.
5. Before changing the visual direction, ask for explicit user approval. Improvements within this direction are welcome; an unrelated redesign is not.

## Approved reference

The approved concept includes the Aivanta marketing homepage, dashboard, workflow canvas, AI assistant, and mobile dashboard in a consistent forest-green / white / lime visual language.
