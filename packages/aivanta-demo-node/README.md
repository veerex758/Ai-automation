# @aivanta/demo-hello

A minimal Aivanta-maintained demonstration package.

## Contract

- Exact version: `1.0.0`
- Runtime API: `1`
- Permissions: none
- Install scripts: none
- Native dependencies: none
- External network or filesystem access: none

The package returns a supplied message (or a fixed greeting). It does not
connect to providers, access workspace credentials, or perform external
actions.

**Safety:** This is a review candidate only. It must not be installed into a
live runtime or executed until the artifact has passed platform review and the
isolated worker and capability broker are available.
